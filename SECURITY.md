# 安全问题 / Security reports

请优先使用仓库提供的私密安全报告入口（如果已启用）。如果没有私密入口，可创建仅请求安全联络方式的 Issue，暂不公开漏洞细节、利用代码或敏感文件。普通功能问题请参见 [CONTRIBUTING.md](CONTRIBUTING.md)。

私密报告中请说明受影响版本、复现条件、影响范围，以及不含个人数据的最小样例。不要上传登录凭据、API 密钥、个人设置或真实账户数据。本仓库不提供实盘交易接入，也不需要这些凭据。

仅当前发布基线接受安全问题评估；尚无长期支持版本或固定修复时限承诺。

Use the repository's private vulnerability-reporting option when enabled. If no private channel is available, open an Issue requesting a security contact method without disclosing vulnerability details, exploit code, or sensitive files. For ordinary bugs, see [CONTRIBUTING.md](CONTRIBUTING.md).

In a private report, include the affected version, reproduction conditions, impact, and a minimal example without personal data. Do not upload login credentials, API keys, personal settings, or real account data. This project has no live-trading integration and does not require these credentials.

Security reports are assessed for the current published baseline. There is no long-term-support branch or guaranteed remediation schedule.
