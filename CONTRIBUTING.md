# 问题反馈 / Feedback

当前主要接受问题反馈。源码公开查看不等于授予修改、使用或再发布许可；提交代码改动前，请先通过仓库 Issues 与维护者沟通所需授权，具体以 [LICENSE](LICENSE) 为准。提交内容不会自动改变项目的许可条款。

报告普通问题时，请提供操作系统、Python 版本、项目版本、复现步骤、预期和实际行为，以及经过脱敏的错误信息。数据相关问题请提供最小合成样例；界面问题可附不含个人信息的截图。不要提交个人设置、真实账户信息、API 密钥、服务器地址、密码、完整私人行情或回测结果。

安全漏洞请使用 [SECURITY.md](SECURITY.md) 中的渠道，避免在公开 Issue 暴露可被利用的细节。

This repository primarily accepts issue reports. Public visibility does not grant permission to modify, use, or republish the source. Before submitting code changes, discuss the necessary authorization with the maintainer through repository Issues; [LICENSE](LICENSE) governs the terms. Submissions do not automatically change the project's licensing.

For ordinary bugs, include your operating system, Python version, project version, reproduction steps, expected and actual behavior, and sanitized errors. Use minimal synthetic data for data-related issues and remove personal information from screenshots. Do not submit personal settings, account information, API keys, server addresses, passwords, or complete private datasets or results.

Use the channels described in [SECURITY.md](SECURITY.md) for vulnerabilities and avoid publishing exploitable details in public Issues.
